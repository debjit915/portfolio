# DEBJIT — Crazy Portfolio

A futuristic, responsive portfolio built from the information in Debjit Debnath's resume.

## Files
- `index.html` — structure/content
- `style.css` — visual design/responsive layout
- `script.js` — particles, boot animation, counters, reveal animations and cursor effects

## Publish for free
### GitHub Pages
1. Create a GitHub repository.
2. Upload the three files.
3. Go to **Settings → Pages**.
4. Select the `main` branch and `/root`.
5. Save. GitHub will publish the site.

### Netlify
1. Create a Netlify account.
2. Drag the `debbjit-crazy-portfolio` folder into the deployment area.
3. Netlify will give you a public URL.

## Customize
- Change colors in `style.css`.
- Replace project descriptions or add project links in `index.html`.
- Replace the contact/social URLs if your profiles change.
- Add a `resume.pdf` beside `index.html` and add a Resume button if desired.
